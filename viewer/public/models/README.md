# Modelos 3D do João

Coloque aqui os seus `.glb` (nenhum código precisa mudar):

- `characters/<id>.glb` — substitui o placeholder do personagem `<id>` (ex.: `characters/clown.glb`)
- `places/<id>.glb` — substitui o cenário do lugar `<id>` (ex.: `places/tavern.glb`)

O `<id>` é o do YAML (`data/characters/<id>.yaml`, `data/places/<id>.yaml`), nunca o nome.
Escala, eixos, origem nos pés e nomes das animações: `docs/guias/06_modelos_3d_e_design.md`.
Depois de copiar, basta recarregar a página da tela (F5).
